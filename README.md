# 🏀 Lades — KTH Basketball Team

A lightweight, real-time scoreboard for the KTH Basketball Team's **Lades** game leading up to the **Osqvik Christmas Party** on **December 5th at 18:00**.

- **Rules:** Catch a teammate accepting an object voluntarily without saying *"Aklımda!"*, *"On my mind!"*, or gesturing → yell **LADES!** (**+1** for you, **-1** for them).
- **Stakes:** Lowest score on December 5th goes into the freezing lake at Osqvik.
- **Local Preview:** Open `index.html?demo=1` in a browser to test with local demo data without touching the live database.
- **Stack:** Vanilla HTML/CSS/JS + Supabase (PostgreSQL + Realtime) + GitHub Pages.
